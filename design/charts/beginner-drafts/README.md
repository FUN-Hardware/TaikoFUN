# TaikoFUN 初心者向け譜面の下書き 5曲

**5曲の音源を同梱しています。「おどるポンポコリン」は音源解析に基づく拍のタイミング調整済みで、試聴とゲーム内確認待ちです。他の4曲は同期調整待ちです。**

ユーザー指定の5曲について、TJA形式の練習パターン案を作成しました。本家のノーツ配置は転記していません。2026-10-11に、ユーザー指定のダウンロード済みMP4から取り出したOGG音源を各曲フォルダへ追加しました。既存の48小節のノーツ配置は保持しています。「おどるポンポコリン」は音源の拍を解析してBPM・OFFSETを調整しましたが、歌の旋律や曲構成に合わせてノーツを作り直したものではありません。

各曲48小節（4/4拍子）の自作パターンです。導入・基本のリズム・短い並び・打ち分け・少し音符を増やす練習・終わりの練習の各8小節で構成します。この区分は練習用で、実際の曲のイントロ・Aメロ・サビの位置を表していません。小節数や長さも曲全体に対応するものではありません。

## おどるポンポコリンのタイミング調整

公式TVサイズ音源のスペクトル変化から拍を検出し、前半・中盤・後半を比較しました。BPMを140から138.94へ、OFFSETを0から-2.083へ更新しました。音源冒頭にほぼ無音の区間があるため、最初のノーツは音源の2.083秒、最後のノーツは83.269秒です。OFFSETの符号は現行ChartLoaderとSongDataの実装を確認しています。

強い立ち上がりを検出できた56ノーツでは、解析上のずれの中央値は9.1ms、95パーセンタイルは21.1msでした。これは波形解析の測定値で、ゲームの実測判定精度ではありません。立ち上がりの弱い音や終わりの歌声は試聴で確認する必要があります。自作の63ノーツ、48小節、Easy/Oniの同一配置は維持しています。

解析結果と未確認事項は [timing_analysis.json](timing_analysis.json) に保存しました。audioSynchronizedとgameRuntimeVerifiedは、試聴・実機確認前なのでfalseのままです。

## 初心者向けの配置

- 小さいドン（1）とカツ（2）のみ。大音符・連打・風船・分岐は入れていません。
- 2拍おきの音符を中心にし、一部だけ短い4分音符の並びを入れています。8分・16分音符はありません。
- 全曲に休憩する小節があります。さんぽはドン中心、夏祭りは短いドンの4連打までを含みます。
- スクロールは0.75倍です。表示の移動速度を変える設定で、音源や叩くリズムの速度は変えません。

## TaikoFUNの現状との対応

各TJAは Easy と Oni の2コースを含み、OniはEasyと同じ簡単な譜面の互換コピーです。これは作成当時の固定コース読込への対応です。現在の統合ブランチには選曲・難易度選択が追加されていますが、今回の譜面をゲームで検証したわけではありません。

ローダーが各小節先頭の0を NoteType::None として残す点を踏まえ、最初の小節はドンから始めています。既存コードの空小節・得点・判定の問題を修正したわけではありません。

このフォルダは自動読込される Songs の外にあります。同期未調整の曲を自動選択させないためです。ゲーム本体、既存のSongs、既存譜面は変更していません。

## 実際の曲の譜面に仕上げる手順

1. 同梱音源と下記の録音版を確認し、使用する区間を決めます。
2. 同梱OGGはTJAと同じフォルダにあり、既存のWAVE:曲名.oggから参照できます。曲フォルダを音源とTJAのセットで使います。
3. BPMとOFFSETを音源に合わせて調整します。他の4曲のOFFSET:0は未調整です。「おどるポンポコリン」は解析値を設定済みで、試聴・実機確認が必要です。イントロや無音、最初に叩く位置も合わせて決めます。
4. 実際の伴奏や歌のリズムに合わせて音符を配置し直し、必要な小節を増減します。48小節のパターンをそのまま曲全体に使えるとは限りません。
5. 調整した曲フォルダを実行環境のSongsに追加し、対象ファイルを選ぶ方法を用意します。コピーだけでは5曲から自由に選べません。
6. Dell G3等の実行可能な環境で、開始・中盤・終盤の同期、手動入力、オートプレイ、リスタートを確認します。LIFEBOOKでは引継ぎの制約に従いゲームのビルド・実行を行っていません。
