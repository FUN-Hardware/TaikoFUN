## 動作

- 自然終了で判定・統計を固定し、ResultCtxを一度だけ保存する。
- 既存の5秒間の余韻の最後0.4秒で暗転。リザルトで0.4秒フェードインし、その後3秒でゲージを伸ばす。
- Backspaceで中断した場合はリザルトを残さず選曲に戻る。Space/半角全角でリスタートすると終了状態・スナップショット・余韻時間をリセットする。
- 良、可、不可（Bad＋Miss）、最大コンボ、連打（通常連打＋風船打数）、スコアを表示。
- 精度 = `(2×良＋可) / (2×通常判定総数)`。連打、風船、破裂回数は分母に含めない。通常判定が0なら0%・C。
- SSは正確に100%、Sは90%以上、Aは80%以上、Bは60%以上、Cは60%未満。整数比で最終判定し、表示は小数2桁で切り捨てる。
- C字ゲージは右上から時計回り270度。100%でも上部の90度の隙間が残る。
- 演出中のDonは演出をスキップ。同じ入力では戻らない。F/Jを両方離した後、次のDonで戻る。入場時の押しっぱなし、F/J同時入力、演出完了フレームの入力も保護する。
- リザルトは音源を再生しない。フォントはシーン終了時に破棄する。

## 検証

LIFEBOOKでは引き継ぎ指示に従いC++ビルド・ゲーム実行を行わない。
DxLib非依存のC++20テストを `tests/result_logic_tests.cpp` に用意し、GitHub Actionsで実行する。
ゼロ判定、重み、ランク境界、99.999%、整数上限、フェード/ゲージ時間、スキップ/押下解除/入場時ホールドを検査する。
Linux等の検証環境では次のコマンドでも実行できる。

```sh
c++ -std=c++20 -Wall -Wextra -Werror -pedantic -fsanitize=undefined -fno-sanitize-recover=undefined -I TaikoFUN/src tests/result_logic_tests.cpp -o /tmp/result-logic-tests
/tmp/result-logic-tests
```
