# 自動デモプレイ

作業ブランチ: `feature/auto-demo-play`。基点: リザルトPR #16を取り込んだ共有ブランチ `4461ef9`。

## 操作と動作

- 選曲一覧で30秒間キーボード操作がないと、現在の曲の自動デモを開始する。
- 難易度選択中、キーを押したまま、非アクティブ中には開始しない。復帰時の長いフレーム時間も待機時間へ加算しない。
- 現在の難易度が存在すれば使用し、なければEasy→Normal→Hard→Oni→裏Oniの順で最初に存在するものを使う。曲のランダム巡回や途中位置からの開始は初版には含めない。
- 音源は先頭から再生。既存ChartPlayer/ChartDrawer/PlayEffectsでオート演奏し、画面下部に「DEMO / キーを押すと選曲へ戻ります」を表示する。入場は0.4秒フェードイン。
- キー入力で即座にデモを停止して元の選曲位置へ戻る。F1・Space・Backspace・半角全角も復帰操作として扱い、デモ内ではオート解除やリスタートを行わない。Escはアプリ終了を維持する。
- 戻るための入力と重なったキーを消費し、全キーを離してから次の選曲入力を受け付ける。新しい待機タイマーは復帰後に開始する。
- 自然終了では1秒間の余韻の最後0.4秒で暗転し、選曲へ0.4秒フェードインして戻る。入力による中断時も音源を即停止し、選曲を0.4秒フェードインする。デモの結果をリザルトへ保存しない。
- 通常演奏は手動開始、F1切り替え、リスタート、中断、既存リザルト遷移を維持する。
- 初版の自動開始/中断判定はキーボードを対象とする。マウス・ゲームパッド入力は未対応。

## 音源とエラー処理

- 通常/デモ開始前に譜面・音源を検査し、選曲の試聴音源を停止・解放してから演奏シーンへ渡す。
- SongSelect::Finalizeは試聴の終了処理のみ。譜面ロードは開始時に行い、終了・復帰で余分な音源をロードしない。
- 自動デモの終了時には音源を停止し、デモ用のChartData参照を解放する。
- 曲一覧が空でも添字アクセスしない。存在しない音源、空の譜面、読み込み例外では選曲に留まる。デモ失敗後は次のキー操作まで自動再試行を停止する。
- 音源が再生開始直後に0msを返しても補間がシステム稼働時間へ飛ばないよう、SongDataの補間基準を再生開始時に設定する。

## 検証

LIFEBOOKでは既存の引き継ぎ制約に従いC++ビルド/ゲーム実行をしない。
GitHub Actions `Auto demo behavior` は次をUbuntuで実行する。

1. DemoLogic: 30秒境界、入力優先、押しっぱなし、非アクティブ/復帰、難易度選択、解除ゲート、入場/終了フェード、終了と中断の競合。
2. 実際のChartPlayer.cpp・SongData.cpp・Input.cppを、テスト専用のDxLib音声/時計/キー境界と組み合わせてコンパイル。先頭0ms、通常判定、連打、風船、終了後の固定、デモ内コントロール禁止、通常のF1相当切り替え/リスタート/中断を検査。
3. 既存リザルトの精度・ランク・演出/入力テストを再実行する。

模擬環境テストはDxLib描画・音声デバイス・Windowsでのアプリ実行の検証ではない。
本番のDxLib呼び出し順や表示/音声は次の実機確認で検証する。
