# TaikoFUN 画面デザイン確認

## 判定・ミニ太鼓・ノーツの見やすさ

`play-readability.html` をEdgeまたはChromeで開いてください。
既存のポスター素材を埋め込んだ、レーン部分の表示確認用プレビューです。
判定のボタンと時間のスライダーで、見逃し・打鍵の不可・空打ち・連続ヒットを比較できます。

- 見逃しでは判定文字を表示せず、コンボをリセットします。
- レーン左に、円形素材と青い帯で組み立てたミニ太鼓を配置します。
- D＝左縁（水色）、F＝左面（赤）、J＝右面（赤）、K＝右縁（水色）。空打ち・不可でも押した部位が0.18秒かけて減衰し、同時押しはそれぞれ光ります。押しっぱなしでは繰り返し発光しません。
- 実ゲームのオートでは良・可の判定で左右交互、大音符は該当する面/縁の両側が光ります。連打・風船は面を左右交互に光らせ、風船破裂は最後の一打と重複発光させません。リスタートで発光と左右順を初期化します。
- HTMLでは4つのボタンかD/F/J/Kキーで表示を確認できます。「オート発光デモ」は模擬入力で、音源やC++の判定とは連動しません。
- レーンの発光 → 星・流線 → 判定枠・ノーツ → 判定文字の順に描きます。
- 星を小さくして0.24秒に短縮し、流線を4本に減らします。
- ゴーゴー中も背景モーションを継続します。既存の`Resource/Image/Playing/gogofire.png`を4列×2行の8コマに分割し、判定枠の周囲に12fps・156pxで描きます。炎は判定枠・ノーツより下に描き、ゴーゴー終了とともに非表示になります。
- HTMLの「ゴーゴータイム」で炎の有無を比較できます。HTMLは表示例で、実音源のゴーゴー区間とは連動しません。

実ゲームには`PlayEffects`と`ChartDrawer`で反映しています。
プレビューのノーツとコンボは表示例で、C++の判定や描画とは連動しません。
今回の環境ではブラウザー確認ツールが起動エラーとなり、表示・操作は未確認です。
ゲームのビルド・実行も未実施です。Dell G3等で確認してください。

## 背景とHUDの画面案

`hud-motion.html` をダウンロードし、EdgeまたはChromeで開いてください。
リポジトリを取得済みなら、このフォルダーの同ファイルを直接開けます。
画像は埋め込まれているため、単独で表示できます。

- 開くと再生し、3秒後から背景が動きます。
- 「一時停止」「再生」で停止・再開できます。
- 経過時間を130秒にすると、加速が終わった状態を確認できます。
- コンボ数と魂ゲージ量は画面下のスライダーで変更できます。

![経過130秒の画面案](hud-motion-at-130s.png)

太鼓・コンボ枠・魂ゲージは、既存の背景の円と横長素材を組み合わせた
仮配置です。数字とゲージ量は表示例で、実ゲームの値とは連動していません。
この3部品の案はプレビューのみで、ゲームへの適用前です。

コンボ枠と数字のモーションは `Scene/Play/View/PlayEffects` に移植済みです。
太鼓と魂ゲージの仮配置は、引き続きプレビューのみです。

ゲーム用変更には、通常時の背景モーション、ノーツとレーンの配色、
白い曲名と連打数の画像表示が含まれます。`Unit-test` の新構造にも
空打ち発光・判定文字・コンボ演出を含めて移植しました。既存の
ゴーゴータイム時の`bg_clear`表示は保持しています。プレビューは
通常時の背景モーションを表示します。
